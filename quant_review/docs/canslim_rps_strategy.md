# CANSLIM + RPS策略使用说明

这份说明是给使用策略的人看的，不是代码说明。

这个页面输出的是“观察池”，不是自动买入指令。它想找的是：基本面增长不差、价格相对强、接近阶段新高、成交活跃、趋势顺势的股票。结果表里的分数和标签，是为了帮你快速排序和复盘，不代表一定可以买。

## 1. 这个策略在找什么

策略有两条主要通道：

- CANSLIM成长通道：偏重“业绩增长 + 相对强度 + 新高/突破形态 + 均线趋势”。适合找增长型强势股。
- 陶博士RPS通道：偏重“中长期RPS强 + 接近一年高位 + 财务排雷 + 机构条件”。适合找长期强势、已经被市场持续认可的股票。
- 双通道共振：同时满足上面两条通道，通常要求更严格，结果更少。

你可以把它理解成三层筛选：

1. 先排除不适合看的股票，例如成交额太小、市值不合适、ST、上市时间太短等。
2. 再看股票强不强，包括RPS、均线、新高、成交量、业绩、市场环境。
3. 最后按总分和RPS排序，只展示前面的一批。

## 2. 页面筛选条件怎么理解

### 2.1 基础设置

- 条件区块：页面把基础主线、CANSLIM交易、陶博士机构、单股执行分成四个区块，默认收起，点击标题展开。
- 复盘模式：盘后复盘使用收盘后的日线数据；盘中预复盘会尝试把实时行情合成当天临时日K，所以盘中结果可能随行情变化。
- 日期：你要复盘的交易日。系统会取不晚于这个日期的实际交易日。
- 展示数量：最终最多显示多少只股票。
- 通道模式：决定保留哪类股票。默认是全部通道，也就是保留通过任一通道的股票；只看CANSLIM只保留成长通道；只看陶博士只保留RPS通道；只看双通道共振只保留两条通道都通过的股票。
- 最低总分：对所有通道都生效，不是只对CANSLIM生效。无论是只看CANSLIM、只看陶博士，还是只看双通道共振，股票都必须先达到这个总分下限，才会进入结果。当前默认60分，偏向先放宽观察池，再由你结合表格细项筛选。

### 2.2 RPS强度条件

RPS可以理解为“相对全市场的强度排名”。例如RPS 90，意思是这段时间的涨幅大约强于全市场90%的股票。

- CANSLIM最低RPS：CANSLIM通道要求综合RPS至少达到这个值。值越高，越偏向龙头和强势股。
- 陶RPS底线：陶博士通道要求50日、120日、250日RPS里至少有一个达到这个底线，表示至少有一个周期足够强。
- 陶核心RPS：陶博士通道的核心强度要求。通常要求120日或250日RPS达到核心值；如果是50日RPS达到核心值，还要求120日RPS也不弱。
- 陶新高位置：收盘价相对一年最高价的位置。例如0.85表示收盘价至少达到一年最高价的85%，或者最近5日已经接近/创出一年新高。

### 2.3 行业主线条件

行业主线评分默认开启，但默认不作为硬过滤。它先给每个行业打分，再影响股票排序：

- 主线行业口径：默认使用申万二级行业，也可以切换申万一级或基础行业。申万数据不可用时会自动回退基础行业。
- 主线过滤：默认“全部股票”，只做加权排序；“主线候选及以上”会保留候选和确认行业；“仅主线确认”最严格。
- 最低主线分：填0表示不按分数硬过滤。设置大于0后，低于该分数的股票不会进入结果。
- 主线权重：默认0.25。最终总分由原始CANSLIM+RPS分和行业主线分加权得到。

行业主线分只使用价格行为，第一版由三部分组成：

```text
行业多周期RPS 50%
+ 行业广度 30%
+ 行业持续性 20%
```

- 行业多周期RPS：行业成分股20、60、120日平均涨幅在全部行业中的百分位，按40%、35%、25%合成。
- 行业广度：成分股站上20日线、站上50日线、个股RPS20达到80的比例。
- 行业持续性：当前、5个交易日前、10个交易日前的行业RPS是否持续靠前。
- 主线确认：主线分至少75，且广度和5日前强度也达标。
- 主线候选：主线分至少60，但尚未完全满足确认条件。

### 2.4 流动性和交易性条件

- 最低成交额亿：成交额太小的股票会被排除。成交额越高，说明交易更活跃，但也不代表越高越好。
- 市值下限亿：排除太小的公司，减少流动性和基本面不稳定的影响。
- 市值上限亿：填0表示不限制上限。设置上限后，可以排除超大市值股票，让结果更偏中小市值。
- 实换手下限%：要求真实换手率不能太低。填0表示不限制下限。
- 实换手上限%：排除换手过热的股票。默认30%，用于减少极端高换手、短线博弈过热的标的。

### 2.5 CANSLIM财务条件

这些条件服务于CANSLIM成长通道。填0表示不检查这一项。

- CANSLIM EPS同比%：要求最近财报EPS同比增长达到阈值。EPS增长代表每股盈利增长。
- CANSLIM扣非EPS%：要求扣除非经常性损益后的EPS同比增长达到阈值。这个指标更关注主营业务质量。
- CANSLIM净利润%：要求净利润同比增长达到阈值。
- CANSLIM营收%：要求营业收入同比增长达到阈值。营收增长能辅助判断增长是否只靠利润率或一次性因素。
- CANSLIM年度EPS%：要求最近年报EPS同比增长达到阈值，观察年度维度是否也有增长。
- CANSLIM ROE%：要求最近年报ROE达到阈值，观察资产盈利能力。

CANSLIM财务通道的特点是：只要你启用了某个财务条件，就要求启用的条件都通过。如果把所有财务阈值都设为0，系统会退而使用成长分或年度质量分做粗略判断。

### 2.6 陶博士财务排雷条件

这些条件服务于陶博士RPS通道。默认都是0，意思是不额外限制。它们更像“排雷”，不是核心打分项。

- 陶EPS排雷%：要求EPS同比不低于这个值。
- 陶净利润排雷%：要求净利润同比不低于这个值。
- 陶营收排雷%：要求营收同比不低于这个值。
- 陶ROE排雷%：要求最近年报ROE不低于这个值。

如果启用了多个陶博士财务排雷条件，则要求全部通过。

### 2.7 陶博士机构条件

机构条件只影响陶博士RPS通道，不影响CANSLIM成长通道。

- 陶机构条件：打开后，陶博士通道会检查基金持股和/或北向持股；关闭后，机构条件直接视为通过。
- 陶机构模式：默认满足任一，也就是基金或北向满足一个即可；基金+北向表示两个条件都要满足。
- 基金持股：是否检查基金持股比例。
- 基金持股%：基金持股比例要达到多少。默认2%。
- 北向持股：是否检查北向持股市值。
- 北向持股万：北向持股估算市值要达到多少万元。默认3000万。
- 机构缺失不拦截：打开后，如果基金或北向数据缺失，不因为缺数据而否决；关闭后，缺数据会按未通过处理。

注意：基金和北向数据通常有滞后，只能作为“是否有机构关注”的辅助证据。

### 2.8 排除项

- 财务指标：关闭后不读取财务数据。CANSLIM成长通道会因为没有财务条件而不通过；陶博士通道会跳过财务排雷。
- 排除ST：剔除名称包含ST的股票。
- 排除科创板：剔除688、689开头的股票。
- 排除创业板：剔除300、301开头的股票。
- 北交所股票：8、4开头的股票始终剔除。
- 上市满180天：上市未满180天的股票会被剔除，避免新股数据太短导致RPS和均线失真。

## 3. 结果表每列是什么意思，怎么算出来

### 3.1 基础信息

- 结果列：默认只显示代码、名称、行业、产业题材、总分、主线行业、主线状态。点击“选择结果列”可以显示更多字段，普通版和早期版分别记住选择。
- 选择框：结果表第一列的复选框。勾选后，点击“复制已选代码”只会复制这些已勾选股票的代码。表头复选框可以一键全选或取消全选当前结果。
- 代码：股票的6位交易代码。
- 名称：股票名称。
- 股票类型：股票基础信息中的类型，用于辅助区分普通股票或其他类型。
- 行业：股票所属行业。没有行业信息时显示“未分类”。
- 产业题材：根据股票代码匹配到的概念、题材或板块信息，帮助你判断它属于什么主线。

### 3.2 策略判断

- 形态：系统对当前图形位置的归类。优先级从高到低是：新高突破、口袋支点、均线回踩、平台突破、强势观察。
- 通道：说明这只股票通过了哪条策略路径。可能是CANSLIM成长、陶博士RPS、CANSLIM+陶博士。
- 陶机构：只看陶博士机构条件是否通过。显示“是”代表机构条件通过或被关闭后视为通过，显示“否”代表未通过。
- 原始分：不含行业主线的CANSLIM+RPS综合分。
- 主线行业、主线状态、主线分：显示股票对应的行业及其当前主线级别。
- 行业RPS、行业广度、持续性：分别说明行业相对强度、内部扩散和排名稳定性。
- 总分：原始分与主线分加权后的最终排序分。默认主线权重25%，即原始分占75%、主线分占25%。

注意：当前页面没有“陶博士专用总分”。无论你选择全部通道、只看CANSLIM、只看陶博士，结果表里的“总分”都按同一套综合评分计算。不同通道的区别在于“先筛谁进结果池”，不是“换一套总分公式”。

陶博士模式下的流程是：

1. 先用陶博士RPS通道筛选：接近一年新高、中长期RPS够强、财务排雷通过、机构条件通过。
2. 再要求统一总分达到页面设置的“最低总分”。
3. 最后仍按统一总分、RPS综合、120日RPS、250日RPS排序。

所以在“只看陶博士”时，最低总分仍然会拦截股票。总分的作用更像二次质量过滤和排序：它不会决定一只股票是否满足陶博士RPS通道，但会决定它能不能过最低总分，以及在结果表里排多靠前。

原始分的计算方式是：

```text
近期成长20%
+ 年度质量10%
+ 新高形态15%
+ 供需10%
+ 相对强度25%
+ 机构关注代理5%
+ 市场环境15%
- 风险扣分
```

也就是说，结果表里的C、A、N、S、L、I、M七个分项，都会先各自换算成0到100分，再按上面的比例加权。最后再扣掉过热或趋势瑕疵带来的风险分。

默认开启主线评分时，最终总分为：

```text
最终总分 = 原始分 × 75% + 行业主线分 × 25%
```

页面修改“主线权重”后会按新的比例计算；关闭行业主线评分时，最终总分等于原始分。

各项分数可以这样理解：

- 近期成长：看最近财报的EPS、利润、营收同比增长。EPS最重要，占近期成长分的大头；利润其次；营收再次。如果EPS同比达到25%以上会额外加分；如果EPS、利润、营收同时都达到较好增长，也会再加分。三项都没有数据时给中性分50。
- 年度质量：看最近年报的年度EPS增长、年度利润增长、年度营收增长、ROE，以及年度EPS是否为正。年度EPS增长和ROE权重较高；全部没有数据时给中性分50。
- 新高形态：先看收盘价离最近一年最高价有多近。越靠近一年新高，基础分越高；最近5日接近或创一年新高会加分；平台突破会加分；口袋支点会加分。
- 供需：看成交额是否足够、最近3日成交额是否比20日均量放大、真实换手是否过热。成交额太小分低；量能温和放大分高；换手超过8%后会逐步降分，避免太热。
- 相对强度：基本就是RPS综合。50日、120日、250日强度越高，这项越高。
- 机构关注代理：这里不是基金或北向持仓本身，而是用成交额、市值、量比估算“是否容易被大资金关注和交易”。真实机构持仓请看后面的基金持股、北向万、陶机构。
- 市场环境：全市场共用一个分数。它看最近5日和20日全市场平均涨跌、上涨股票比例、站上50日线比例、均线趋势比例。市场越强，这项越高。

风险扣分主要有四类：

- 距50日线太远：如果收盘价比50日线高太多，认为短期过热，会扣分。
- 当日涨幅过大：如果单日涨幅超过约10.5%，会扣分，避免涨停或接近涨停后的追高风险。
- 离一年高点太远：如果新高位置低于0.75，会扣分，说明还不够接近强势区。
- 均线结构不够强且RPS综合不够高：如果不是均线多头，同时RPS综合又不到95，会扣分。

所以总分不是单纯看涨幅，也不是单纯看财务。高总分通常意味着：业绩不差、RPS强、形态接近强势区、成交活跃但不过热、市场环境也配合。

### 3.3 RPS强度

- RPS综合：由50日、120日、250日RPS加权得到。公式是：50日RPS占25%，120日RPS占35%，250日RPS占40%。这个值越高，说明中长期越强。
- RPS50：最近约50个交易日涨幅在全市场里的百分位排名。100最好，90表示强于约90%的股票。
- RPS120：最近约120个交易日涨幅在全市场里的百分位排名。
- RPS250：最近约250个交易日涨幅在全市场里的百分位排名。

如果历史交易日不足对应周期，就用已有历史里最早的收盘价作为涨幅基准。

### 3.4 CANSLIM七项分数

- C：近期成长分。主要看最近财报的EPS、利润、营收同比增长。三项都缺失时给中性分50。
- A：年度质量分。主要看最近年报的年度EPS增长、年度利润增长、年度营收增长、ROE，以及年度EPS是否为正。全部缺失时给中性分50。
- N：新高/形态分。越接近一年新高分越高；5日内接近或创一年新高、平台突破、口袋支点都会加分。
- S：供需分。主要看成交额、近期量能是否放大、真实换手是否过热。成交额太低不好，换手过热也会降低分数。
- L：领导力分。基本等同于综合RPS，表示这只股票是不是市场里的相对强者。
- I：机构关注代理分。这里不是实际机构持仓，而是用成交额、市值、量比做流动性代理。真实机构条件看“陶机构”“基金持股”“北向万”等列。
- M：市场环境分。全市场同一天共用一个分数，来自大盘广度、等权涨跌、站上50日线比例、均线趋势比例等。

### 3.5 价格、成交和市值

- 收盘：当前交易日收盘价；盘中模式下可能是实时行情合成的临时价格。
- 涨跌%：当前交易日涨跌幅。
- 成交额亿：当前交易日成交额换算成亿元。
- 量能比：最近3日平均成交额除以最近20日平均成交额。大于1代表近期量能比20日均量更活跃。
- 实换手%：真实换手率，用来观察筹码交换是否充分，也用于实换手上下限过滤。
- 总市值亿：总市值换算成亿元，用于市值上下限过滤和机构关注代理分。

### 3.6 涨幅、位置和形态细节

- 50日%：当前收盘价相对约50个交易日前收盘价的涨幅。
- 120日%：当前收盘价相对约120个交易日前收盘价的涨幅。
- 250日%：当前收盘价相对约250个交易日前收盘价的涨幅。
- 新高位置：当前收盘价除以最近约250个交易日最高价。接近1代表接近一年高点。
- 距20日%：当前收盘价相对20日均线的偏离百分比。正数表示在20日线上方。
- 距50日%：当前收盘价相对50日均线的偏离百分比。过高会被视为短期过热并触发风险扣分。
- 均线多头：显示是否满足收盘价在50日线上方，且50日线在120日线上方，120日线在200日线上方。
- 5日新高：最近5日内最高价是否已经接近或达到最近250日最高价。
- 口袋支点：一种放量转强形态。要求当天涨幅不低于3%，收盘不低于开盘，当天成交额超过最近10日下跌日的最大成交额，并且最低价靠近10日、20日或50日均线。

### 3.7 机构数据

- 基金持股%：最近可用基金持仓报告中，基金合计持有该股流通股比例。
- 基金期：基金持股数据对应的报告期。
- 北向万：北向持股数量乘以当前价格后估算出的持股市值，单位万元。
- 北向%：北向持股比例。
- 北向期：北向持股数据对应的日期或报告期。
- 机构说明：把机构判断过程写成人话，例如要求基金和北向同时满足，当前基金持股是多少，北向持股是多少，阈值是多少。

### 3.8 财务数据

- EPS同比%：最近财报每股收益同比增长。优先使用扣非EPS同比；没有时使用基本EPS同比；东财兜底时用本期EPS和上年同期EPS推算。
- 扣非EPS同比%：扣除非经常性损益后的EPS同比增长。更能反映主营业务盈利变化。
- 基本EPS同比%：基本每股收益同比增长。
- 单季EPS：最近财报的单季每股收益；东财兜底时可能使用报表EPS。
- 利润增速%：最近财报利润同比增长。优先使用单季净利润同比，其次使用其他利润同比口径。
- 营收增速%：最近财报营业收入同比增长。
- 年度EPS同比%：最近年报EPS同比增长，用于观察年度维度是否持续增长。
- ROE%：最近年报净资产收益率，用于观察资产盈利能力。
- 报告期：当前行使用的是哪一期财报。
- 财务状态：说明财务数据是否正常读取。例如已读取、东财兜底、读取失败、已关闭、无匹配财报。
- 财务说明：解释财务数据来源、覆盖情况或缺失原因。

### 3.9 风控和解释

- 风控提示：根据形态给出的观察线。新高突破和平台突破通常看20日线或突破日低点；均线回踩看50日线；口袋支点看支点日低点。它只是提示，不是自动止损指令。
- 理由：系统把这只股票入选的主要原因压缩成一句话，例如通过了哪条通道、是否5日新高、是否口袋支点、是否均线多头、EPS是否达标、市场环境是否支持等。
- 操作：前端按钮列。点击“复制整行”会复制这一行和表头，方便粘贴到复盘笔记。

## 4. 候选池最终怎么排序

最终结果必须先满足：

1. 通过基础过滤，例如价格有效、成交额、市值、换手、板块排除、上市时间等。
2. 总分达到页面设置的最低总分。
3. 至少通过一条策略通道。
4. 符合你选择的通道模式。

排序顺序是：

1. 总分从高到低。
2. 总分相同或接近时，看RPS综合从高到低。
3. 再看120日RPS。
4. 再看250日RPS。

所以排在前面的股票，一般是综合分更高、相对强度更高、中长期趋势更强的股票。

## 5. 单股分析怎么看

单股分析不是只在结果池里查找，而是会先计算全市场数据，再解释这只股票为什么通过或为什么没通过。因为RPS必须基于全市场排名，不能只看单只股票。

单股分析会逐项检查：

- 价格是否有效。
- 成交额是否达到要求。
- 市值是否在上下限内。
- 实换手是否在上下限内。
- 是否被ST、科创板、创业板、北交所、上市未满180天等规则排除。
- 总分是否达到最低要求。
- CANSLIM综合RPS是否达到要求。
- CANSLIM成长通道是否通过。
- 陶博士RPS通道是否通过。
- 陶博士机构条件是否通过。
- 是否符合当前通道模式。

如果某只股票你主观看好但没有进入结果池，优先看单股分析里“未通过”的项目，这比只看结果表更有用。

## 6. 使用时的几个提醒

- RPS高说明走势强，不代表估值便宜，也不代表马上可以买。
- 接近一年新高是强势信号，但离均线太远时也可能短期过热。
- 财务数据有披露滞后，机构持仓数据也有滞后，不能只看单一指标。
- 双通道共振结果少是正常的，因为它同时要求成长、强度、位置和机构条件。
- 这套策略更适合做复盘观察池，真正交易还要结合大盘环境、板块主线、买点位置和个人风控。
