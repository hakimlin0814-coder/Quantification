# 低价暗语新低策略说明

## 策略条件

策略只保留同时满足以下条件的股票：

1. 使用全市场实时行情中的**当日最低价**。
2. 当日最低价命中至少一种数字暗语。
3. 当日最低价不高于此前 `N-1` 个交易日的最低价，即它是含当日在内的近 `N` 个交易日最低价。

`N` 默认是 `20`，页面中可以修改。为保证窗口完整，上市交易天数不足的股票不会进入结果。

## 股票范围过滤

页面提供三个可单独开关的过滤项，并且默认全部勾选：

- 过滤 ST：排除名称以 `ST`、`*ST`、`S*ST` 等标记开头的股票
- 过滤创业板：排除代码以 `300`、`301` 开头的股票
- 过滤科创板：排除代码以 `688`、`689` 开头的股票

取消勾选后，对应股票会重新参与实时暗语和新低判断。

## 二级行业市值排名

“二级行业市值前 N”使用申万二级行业和 `daily_basic.total_mv` 总市值计算：

- 每个申万二级行业内按总市值从大到小排名
- 默认填写 `5`，只保留各二级行业市值前 5 名
- 填写 `0` 表示关闭该条件
- 实时筛选使用最近可用交易日的总市值
- 历史回测按每个信号日的历史总市值重新排名，避免使用当前市值替代历史市值

结果中会显示申万二级行业、总市值和行业市值排名。

## 价格如何转成暗语数字

价格统一保留两位小数，再去掉小数点进行识别。整数部分不限位数。

- `7.77` 转成 `777`
- `23.32` 转成 `2332`
- `1234.43` 转成 `123443`
- `1111.11` 转成 `111111`

结果中的“数字串”列会显示实际参与识别的内容。

## 暗语类型

### 1. 叠数

- 全同数：全部数字相同，例如 `7.77`、`11.11`、`1111.11`
- 尾部连续叠数：价格数字串末尾连续出现两个或更多相同数字
- 尾数对子：`.11`、`.22`、`.33`、`.44`、`.55`、`.66`、`.77`、`.88`、`.99`
- 多组对子：例如数字串 `112233`

### 2. 重复片段

- 两位交替重复：`ABAB`、`ABABAB`
- 三位或多位片段重复：`ABCABC`、`XYZXYZ`
- 重复片段必须覆盖完整数字串，不再从任意局部硬找重复关系

### 3. 对称回文

- 整体回文：`ABA`、`ABBA`、`ABCBA`、`ABCCBA`
- 整数部分回文
- 整数末两位与小数两位倒序呼应

例如 `7.87`、`23.32`、`1233.21`、`1234.43`。

### 4. 顺子

- 正顺子：相邻数字逐位加一，例如 `7.89`、`12.34`、`1234.56`
- 倒顺子：相邻数字逐位减一，例如 `7.65`、`43.21`
- 顺子必须覆盖完整价格数字串，不支持 `9` 到 `0` 的循环拼接
- 至少连续三位才会识别

策略不再识别等差奇偶、数字运算、整数关口、临界尾数或吉利特殊尾数。

一个最低价可以同时属于多个大类，结果会完整列出，不只保留第一个命中类型。

## 放量和缩量

量能默认与**前5个完整交易日的平均成交量**比较，页面可以修改基准天数。

- 量能倍数 = 截至当前成交量 / 前若干完整交易日平均成交量
- 变化百分比 = `(量能倍数 - 1) × 100%`
- “量能变化阈值%”默认是 `20`
- 当前成交量比均量高至少 `20%` 才显示“放量”
- 当前成交量比均量低至少 `20%` 才显示“缩量”
- 未达到正负阈值时显示“基本持平”

页面只填写一个阈值，并根据“量能范围”使用对应方向。例如阈值填 `30`：只看放量时要求变化不低于 `+30%`，只看缩量时要求变化不高于 `-30%`，选择全部量能时同时保留这两种方向。

量价方向是硬过滤条件：

- 当天股价上涨，必须同时放量才符合
- 当天股价下跌，必须同时缩量才符合
- 平盘、上涨缩量、下跌放量以及量能基本持平均不符合

页面的“量能范围”还可以进一步选择：

- 全部量能：保留符合量价方向规则的放量和缩量信号
- 只看放量：只保留当天上涨且放量的信号
- 只看缩量：只保留当天下跌且缩量的信号

该选择会同时用于实时筛选和历史回测。

点击结果表的“放缩量”表头时，按照实际的“量能变化%”数值排序，而不是按照“放量/缩量”的文字排序。升序会优先显示缩量幅度更大的股票，降序会优先显示放量幅度更大的股票。

盘中成交量尚未走完整天，因此早盘出现“缩量”很常见。它表示截至当前的进度，不是收盘后的最终量能结论。

## 结果列

实时结果支持自行勾选显示列。默认只显示：

- 代码
- 名称
- 行业
- 实时最低价
- 放缩量

代码和名称固定保留，其余列可以自由显示或隐藏。“导出CSV”和“复制整行”使用当前已显示的列。

结果表第一列提供逐行多选框和全选框。勾选股票后可以：

- 复制勾选股票代码
- 只导出勾选结果
- 只回测勾选股票

如果没有勾选任何股票，回测默认使用当前策略条件扫描全市场。

## 次日收盘回测

点击“次日收盘回测”可以按历史正式日K重新生成信号。

- 历史信号必须满足与实时策略相同的严格暗语、`N` 日新低、股票范围过滤和量价方向条件
- 回测继承页面当前的“全部量能 / 只看放量 / 只看缩量”选择
- 回测同时继承页面填写的“量能变化阈值%”
- 实时结果中勾选了股票时，回测股票池只包含这些股票；未勾选时回测全市场
- 次日必须是紧接信号日的下一市场交易日；股票次日停牌或没有正式日线时，该信号不进入结果
- 次日涨跌幅 = `次日收盘价 / 信号日收盘价 - 1`
- 回测结果展示信号日最低价、暗语明细、信号日收盘、次日收盘、次日涨跌和信号日放缩量
- 汇总包含信号数、次日上涨/下跌数量、胜率、平均值、中位数、最佳和最差涨跌
- 按暗语大类汇总信号数、次日上涨/下跌数量、胜率、平均涨跌和中位涨跌，并标出胜率最高的暗语

一条信号如果同时命中多个暗语大类，会分别计入各大类统计，因此各暗语信号数之和可能大于总信号数。胜率相同时，优先显示信号数更多的暗语；信号数仍相同时，再比较平均次日涨跌。

回测是逐信号事件统计，不模拟仓位、手续费或次日开盘买入。

## 批量参数扫描

回测弹窗中的“批量参数扫描”用于一次比较多组量能阈值。扫描会沿用当前的：

- 回测开始和结束日期
- 新低交易日数 `N`
- 量能平均天数
- ST、创业板、科创板过滤
- 页面勾选的股票范围
- 暗语识别和次日收盘统计规则

可以选择同时扫描放量和缩量，或者只扫描一个方向，并设置：

- 新低最小N、最大N和步长，默认 `10` 至 `50`、步长 `10`，即扫描 `10、20、30、40、50` 日新低
- 量能最小阈值、最大阈值和步长，例如 `10%` 至 `100%`、步长 `10%`
- 二级行业市值排名可设置最小值、最大值和步长，默认从前 `1` 扫描到前 `5`，步长为 `1`

扫描按照最大新低天数一次读取历史行情和逐日市值排名，再在同一份数据上生成各个新低N的基础信号，并在内存中切分行业市值前 N、量能方向和阈值，不会为每组参数重复请求历史行情。

结果展示每组参数的新低N、行业市值前 N、量能方向、量能阈值、信号数、股票数、次日胜率、平均涨跌、中位涨跌、最佳/最差涨跌和最佳暗语。页面还可以设置最低样本数。只有同时满足“样本数达标”和“平均次日收益为正”的组合才参与“推荐参数”选择；没有这样的组合时会明确显示暂无推荐。推荐顺序依次比较：

1. 次日胜率
2. 平均次日涨跌
3. 信号数量

参数扫描用于寻找候选范围，不应只采用历史胜率最高的一组。建议优先选择样本充足、相邻阈值表现接近且在不同时间区间都相对稳定的参数。

## 使用提醒

数字暗语是价格形态分类，不代表这些数字本身具有预测能力。该策略用于快速找到“实时新低位置恰好出现明确重复、对称或顺子结构”的股票，仍需结合趋势、基本面、流动性和市场环境判断。
