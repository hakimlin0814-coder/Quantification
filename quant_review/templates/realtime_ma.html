批量实时MA检查说明

判断条件

  • 回踩5日均线 = 今日最低价 <= MA5 <= 当前价格 <= 今日最高价，并且 MA5 > MA10 > MA20 > MA30 > MA60。
  • 回踩10日均线 = 今日最低价 <= MA10 <= 当前价格，并且 MA5 >= MA10。
  • 回踩20日均线 = 今日最低价 <= MA20 <= 当前价格，并且 MA10 >= MA20。

数据口径

  • 实时价格、今开、今高、今低、昨收来自 Tushare `rt_k`。
  • 均线用历史日线收盘价加当前实时价计算，相当于盘中临时日K。
  • 是否跌破各均线 = 当前价格低于对应均线。

使用方式

  • 可以粘贴股票代码、TS代码或股票名称，支持多行、空格、逗号混合。
  • 点击“刷新实时数据”会按表格内股票重新拉取 `rt_k` 并重算条件。
  • 点击表头可以排序，适合把符合条件或跌破均线的股票排到前面。
