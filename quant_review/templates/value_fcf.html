低估值现金流策略说明

策略定位

  • 这个策略是“估值便宜 + 盈利质量不差 + 现金流真实”的观察池，不是自动买入信号。
  • 它更适合找被市场压低估值、但仍能产生股东回报和现金流的公司，偏中低频、偏价值防守。
  • 结果需要结合行业景气、资产质量、财报一次性项目、分红和负债结构再做人工判断。

核心指标口径

  • PB：市净率，默认要求小于 1。它代表市场价格低于账面净资产，但低 PB 也可能反映资产质量折价。
  • PE_TTM：滚动市盈率，默认要求小于 15，并且必须为正。负 PE 不会被当成便宜。
  • ROE：净资产收益率，默认要求大于 15%。这里优先使用 Tushare 财务指标；如果接口不支持全市场读取，会用东财业绩报表兜底。
  • FCF率：自由现金流收益率，默认要求大于 4%。精确口径为 TTM 自由现金流 / 总市值。

FCF怎么计算

  • 优先口径：自由现金流 = 经营活动现金流净额 - 购建固定资产等支付的现金。
  • TTM口径：非年报期会尽量用“本期累计 + 上年年报 - 上年同期累计”换算滚动十二个月。
  • 兜底口径：如果 Tushare 现金流接口要求逐股读取、无法全市场读取，页面会用东财现金流量表近似为“经营现金流 + 投资现金流”。
  • 兜底口径不是严格自由现金流，结果表里的“FCF口径”会明确标出来，避免混用。

筛选顺序

  • 第一步：读取股票基础信息、最新日线和 daily_basic 估值数据。
  • 第二步：读取 ROE 和现金流数据，生成最近报告期和 TTM 现金流口径。
  • 第三步：剔除无市值、无有效估值、PE 非正、PB 非正、ROE 或 FCF 不达标的股票。
  • 第四步：按 FCF率、ROE、PE、PB 排序，优先展示现金流回报更高、盈利能力更强、估值更低的标的。

参数怎么调

  • PB上限：默认 1。想更严可设 0.8，想扩大样本可设 1.2。
  • PE_TTM上限：默认 15。成熟行业可以更低，成长性仍在的公司可适度放宽。
  • ROE下限：默认 15%。如果结果太少可降到 10%，如果只看优秀资产可提到 18% 或 20%。
  • FCF率下限：默认 4%。想找现金流更厚的公司可提到 6% 或 8%。
  • 任一数值填 0 表示不限制该项，适合临时放宽观察。

读表方式

  • 先看 PB、PE_TTM 是否真的便宜，再看 ROE 是否稳定高于门槛。
  • 重点看 FCF率 和 TTM FCF亿，避免只靠账面利润筛到现金流很弱的公司。
  • 看“ROE报告期”和“现金流报告期”，确认使用的是最近可用财报。
  • 看“FCF口径”，如果出现东财近似口径，建议把它当作初筛线索，再打开财报核对资本开支和投资现金流构成。

风险提示

  • 低 PB 可能来自坏账、存货、商誉、地产或周期资产折价，不等于安全。
  • 高 ROE 可能来自高杠杆，需要结合资产负债率和现金流稳定性。
  • 高 FCF率 可能来自一次性收款、资本开支短期收缩或周期高点，需要看多年连续性。
  • 这个策略适合作为价值观察池，最好再叠加行业景气、分红、负债和价格趋势判断。
